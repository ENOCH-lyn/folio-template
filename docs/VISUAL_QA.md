## 3. 人工审图清单

- [x] **栅格**：按 `G` 打开栅格叠层，卡片、标题和 Meta 的左右边缘都落在栏线上。
- [x] **层级**：一屏内荧光橙不超过 2 处；中文副标比英文更小、更灰。
- [x] **对比度**：Header 使用 `difference` 混合，在网点、图片、深色区块上都能读清。
- [x] **页边距**：所有内容（含扇形色卡展开后的顶角）都在 `--margin` 以内。
- [x] **单行约束**：Header、区块计数、Mono 标签不出现意外折行。
- [x] **暗房主题**：流程区和页脚在暗色主题下反转为纸色，形成节奏，属于设计意图。

- [x] **焦点**：键盘 Tab 可达所有交互元素，`:focus-visible` 为 2px 橙色轮廓。
- [x] **降级**：reduced-motion 下 Hero 显示静态网点帧，色卡扇直接呈现展开终态，没有平滑滚动和跑马灯。

## 4b. 第二轮：OPERATOR FILE 改版验收（2026-10-13）

反馈：「背景是经典的 Claude 黄灰配色，风格偏传统视觉；作品带二次元元素，想要二游官网那种现代、炫酷感」。
处理：保留动效系统，视觉语言整体替换为黑橙战术 HUD（见 `DESIGN_SYSTEM.md` v2.0），默认 NIGHT 主题，可切 DAY 冷白灰。

| # | 视口 | 问题 | 原因 | 修复 |

| R2-1 | 全部 | 页面可横向滚动 10px（1440 → 1450） | 区块标题的描边水印 `right: -0.04em` 越出版心 | 水印 `right: 0`，`.section-head` 加 `overflow-x: clip` |

### 人工审图结论

- NIGHT：黑底 + 信号橙主导，青色仅出现在网点第二色版与 SR 角标，未出现暖灰 / 米色。
- DAY：冷白灰底，网点第二色版为黑，橙色强调不变；与 NIGHT 层级一致。
- 切角、斜带、水印、编号在三个断点下均对齐栅格（`G` 叠层截图 `*-20-grid-overlay.png`）。
- 装备卡扇、横向流程、列表视图 hover、案例页过场在三个断点下均无裁切异常。

## 5. 已知事项（非缺陷）

- **占位图片**：模板图片使用 AI 文生图接口按 prompt 实时生成。验收期间接口对全部 prompt 持续 302 到默认图（「The image is generating… Please refresh page」），所以截图里的作品图都是这张占位图。图片生成完成后刷新页面即可看到真实画面；**替换为自己的作品图时，直接修改 `src/content.ts` 里的 URL 即可**，无需改动其他代码。
- **占位图自带黑边**：默认占位图本身带一圈黑色粗描边，出现在卡片 b 和关于区肖像上方，不是样式问题。
- **截图里的光标圆环**：自动化截图会把自定义光标一并截进去（画面中央的小圆环），真实使用时它跟随鼠标。

## 6. 如何复验

```bash
npm run build
npx vite preview --port 4173 --strictPort   # 另开终端
npm run qa                                  # 全量：3 视口 × 2 主题 + reduced
QA_ONLY=390-light,1024-dark npm run qa      # 只跑指定组合
QA_SKIP_WARM=1 npm run qa                   # 跳过图片预热轮询
```

可选环境变量：`QA_URL`（默认 `http://localhost:4173/`）、`CHROME_PATH`（默认 macOS 上 Chrome 的安装路径）、`QA_WARM_TIMEOUT`（图片预热超时秒数，默认 300，设为 0 跳过预热）。
